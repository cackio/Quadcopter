# 软件验证记录

日期：2026-11-02。验证对象是当前本地工作区，尚未提交 Git。

## 构建

使用 ARM Compiler for Embedded 6.24，目标 Cortex-M4／FPv4-SP-D16／硬浮点，C99。`tools/build_firmware.py` 读取实际 Keil 工程的源文件与包含目录，每个配置编译 40 个 C/汇编单元并完成链接和 Intel HEX 导出。

| 输出目录（build 下） | 配置 | ROM 字节 | RW＋ZI 字节 | 编译链接 |
|---|---|---:|---:|---|
| `firmware` | 默认六轴／9600／欧拉角20Hz | 40816 | 23640 | 通过 |
| `fixed9600` | 固定姿态／9600 | 40996 | 23640 | 通过 |
| `diag9600` | 原始数据与时间诊断／9600／10Hz | 40544 | 23640 | 通过 |
| `ano115200` | 六轴／115200／欧拉角＋四元数50Hz | 41056 | 23640 | 通过 |
| `marg9600` | 请求九轴／9600，默认未标定时回退六轴 | 40816 | 23640 | 通过 |

每个目录均包含 `quadcopter.axf`、`quadcopter.hex`、`quadcopter.map` 和 `build.log`。链接范围为 Flash 0x08000000／512KB，SRAM 0x20000000／96KB。没有自动下载到开发板。

九轴请求配置不包含虚构的有效校准参数：当前工程 `CAL_MAG_VALID=0`、两个轴确认标志为 0，所以该固件仍会按设计回退六轴。实际九轴算法的数学路径已在电脑端 C 测试中验证；实机启用需完成轴映射和校准。

编译中保留了原有 μC/OS-II 的自赋值告警和 ARMASM 旧汇编器弃用提示，没有为压掉这些提示改写第三方内核或用户原有汇编修改。详情可在各配置 build.log 中检查。未实际运行 CubeMX 再生成或 uVision GUI 构建；已同步 .ioc，新增源文件已纳入 Keil 项目，生成函数与自定义回调分开，RTOS ISR 钩子位于相应 USER 区。

## 自动测试

命令：`python tools/run_tests.py`。

最终结果：**28 passed**。

- 使用 MinGW GCC 13.1.0 编译实际 `attitude.c`、`ano_protocol.c`、`imu_driver.c`，通过 ctypes 调用，使用 `-Wall -Wextra -Werror`。
- 三个轴以已知角速度积分 90°；六轴倾斜姿态收敛；九轴含倾斜的已知航向收敛；磁场移除与恢复时四元数连续。
- 无效 dt、NaN、零向量、零梯度、四元数归一化、右手旋转矩阵校验、显示坐标变换、静止零偏及移动重置。
- 微秒计数器回绕；已过期有效性不会在后续回绕时重新生效。
- MPU 的初始化、配置读回失败、AD0 高地址、带状态的连续读取、有符号边界、未就绪不覆盖样本、BUSY 快速失败；HMC 身份、X/Z/Y 顺序、溢出处理。I2C 使用 HAL 模拟层，不代表实机总线测试。
- 实际 C 生成的零欧拉角、单位四元数与已知字节一致；量化和边界保护；61字节诊断载荷与 Python 共用定义并逐字段解码。
- 噪声、错校验、错长度、分片、截断后恢复；载荷内含帧头字节不会误切帧；实际 C 诊断帧能够保存、回放为 CSV。
- 合成完整软铁椭球和硬铁偏置恢复；平面数据、样本不足及移动六面数据拒绝；生成头文件保留其他参数且能通过 C 编译；旧融合模型的拒绝不会妨碍重新采集原始标定数据。

Python 环境：3.9.13；NumPy 1.24.4；SciPy 1.9.1；pyserial 3.5；pytest 7.1.2。测试入口禁用无关的系统 pytest 插件，以免加载本工程不需要的环境插件。
