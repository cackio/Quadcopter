# GY-86 独立传感器校准与验收

本阶段先检验原始测量，再计算补偿并用新数据验收。独立校准模式不运行 Madgwick，不向匿名上位机发送正常姿态；固定帧能收只证明发送链路，本工具还会检查反向命令链路。

## 1. 接线、编译和烧录

拆桨，保持电机关闭，GY-86 固定在最终安装位置。I2C1 使用 PB6 SCL、PB7 SDA，检查电平、上拉及共地。

| STM32 | JDY-31 | 用途 |
|---|---|---|
| PA9 TX | RXD | 板子向电脑发送 |
| PA10 RX | TXD | 电脑向板子发送命令，不能漏接 |
| GND | GND | 共地 |

模块实际 UART 配置与固件当前均为 115200、8N1。`sensor_check.py` 默认仍为 9600，使用当前固件时命令须带 `--baud 115200`。选择实际电脑的蓝牙传出 COM；关闭匿名上位机、SSCOM 等占用同一 COM 的程序。

```powershell
cd F:\cubemx_project\test\Quadcopter
python -m pip install -r tools/requirements.txt
python tools/build_firmware.py --name sensor-cal --define FLIGHT_APP_MODE=1
```

烧录 `build/sensor-cal/quadcopter.hex`；脚本只编译，不下载。**下载后要复位并运行**：按板上RST或重新上电；Keil调试中使用Reset再Run。仅继续运行RAM中的下载程序不会启动应用。Keil 用户也可在 C/C++ Define 中加入 `FLIGHT_APP_MODE=1`，Rebuild 后下载。此模式强制采用校准采集和10Hz诊断，不必再改遥测宏。原默认 `FLIGHT_APP_MODE=0` 为姿态模式。

## 2. 原始数据检查

```powershell
python tools/sensor_check.py --list
python tools/sensor_check.py --port COM9 --baud 115200 --stage link --output captures/link_check_01
python tools/sensor_check.py --port COM9 --baud 115200 --stage raw --seconds 15 --output captures/raw_check_01
```

COM9 是示例，按实际电脑选择；输出目录必须是新目录。程序先查模式、身份和初始化，再显示 RAW 加速度 /16384（g）、角速度 /65.5（°/s，未扣零偏）和磁场整数。

`link`只查询双向通信、固件和传感器状态，不触发采样校准。失败时查看发送/接收字节数、收到的F1/03/F3等帧类型以及session.json的communication记录。收到0字节时先查应用是否启动；已经收到F1却没有应答时再查反向线路及固件版本。当前驱动会短暂等待上一笔I2C STOP释放，持续忙超过1ms才报stage=5。

先静止，再分别绕原生轴转动。静止加速度模长约1g；转动时对应角速度应变化。`seq` 表示新样本序号；相同的静止数值不代表同一个样本。

周期使用板上完整计数检查，初始要求180–220Hz、4.5–5.5ms间隔占比至少95%。10Hz蓝牙CSV不能独自证明200Hz正常。异常先查I2C、TIM4和任务耗时。

初始化失败查看 `stage/register/expected/actual/hal_status/hal_error`。stage：0无失败记录、1读失败、2写失败、3身份不符、4读回不符、5总线忙。读回失败时 HAL 本身可能成功，不要只看 hal_status=0。MPU失败停止校准；磁力计缺失可继续MPU校准。

## 3. 陀螺仪零偏与独立验证

```powershell
python tools/sensor_check.py --port COM9 --baud 115200 --stage gyro --output captures/gyro_01
```

工具等待上电至少30秒预热，提示放稳后回车。机架不必严格水平，但必须人工确认静止。板上先确认200个稳定样本，再累计1000个新样本；界面显示进度、重启次数和原因。软件不能证明机架没有匀速慢转。

计算后自动重新采另外1000点，检查扣零偏后的三轴均值，每轴初始目标绝对值≤0.1°/s、标准差≤0.2°/s。零偏只在本次运行有效，不写Flash。记录温度；30秒预热不等于完整温度补偿。

## 4. 加速度六面与12个独立倾角

```powershell
python tools/sensor_check.py --port COM9 --baud 115200 --stage accel --output captures/accel_01
```

先完成本次上电零偏，再按提示把原生+X、−X、+Y、−Y、+Z、−Z朝上，每面固定后回车。这里是传感器轴，不是尚未确认的机头/左右。每面板上统计1000点，蓝牙只上传均值、标准差和进度。

保持现有模型 `a_native_g=(raw/16384-bias_g)*scale`，再通过独立轴映射转换到机体系。工具拒绝缺面、样本不足、移动、错面、比例异常和交叉轴残差过大。

采满1000点只表示完成静态采样，不表示该轴已经摆正。若报“六面方向一致性未通过”，查看全部六面的补偿向量和0.08g向量残差；角度只是当前对角模型下的方向误差，不能直接认作真实机械倾角。以传感器原生轴为准使用夹具，不直接拿机架表面作参考。未经校准的另两轴不必严格读0，它们可能有偏置。准确摆正后仍失败时再检查交叉轴误差，不能直接放宽门限。

六面统计会在拟合前保存，失败也可查看 `六面统计.csv` 和 `session.json` 中的faces/face_quality；不会生成有效校准头文件。

拟合后另外摆12个静止倾角，覆盖上下、左右和前后，不能反复平放。检查窗口均值向量补偿后的模长0.98–1.02g，同时检查噪声和空间覆盖。模长正确仍不等于方向和已知倾角正确。

### 加速度采集中断后续采

如果六面已经通过，独立验证第7个姿态等阶段因噪声超时，不必重做前面的全部步骤。保留原目录，用新输出目录续采：

```powershell
python tools/sensor_check.py --port COM12 --baud 115200 --stage accel --resume captures/accel_01 --output captures/accel_resume_01
```

工具会从原 `session.json` 和 `采样统计.csv` 恢复完整1000点、噪声与周期合格的窗口；旧版本只把前6个独立姿态写进CSV，也可以恢复。第7个未完成窗口不会拼接或算通过，重新采集第7个，再继续后面的姿态。原目录保持不变。

续采要求同一传感器、量程、安装和编译系数。若板上零偏仍有效且与原会话一致，复用原零偏及其独立验证记录；若板子重启或零偏变化，只重做本次零偏，保留完成的六面和独立加速度窗口。配置不一致则拒绝恢复。

新版每完成一个面/独立姿态即原子保存JSON及统计CSV。等待静止时因噪声、移动或加速度范围异常而超时，可以回车只重试当前姿态，或输入q退出后续采。I2C错误不会自动重试或恢复，噪声门限不放宽；最终仍须凑齐12个独立倾角并通过模长及空间覆盖检查，才导出有效参数。

## 5. 磁力计校准与独立验证

```powershell
python tools/sensor_check.py --port COM9 --baud 115200 --stage mag --seconds 240 --mag-verify-seconds 90 --output captures/mag_01
```

保持最终装配和供电，电机关闭，远离铁桌、磁铁和强电流设备。缓慢翻转整个机架，覆盖各轴；只水平旋转不足以拟合三维椭球。

HMC内部30Hz、蓝牙抽取约10Hz。训练至少1000个有效新点、300个不同向量，检查三维及八个方向覆盖；要求至少90%内点、内点相对RMS≤5%，输出硬铁偏置和对称正定软铁矩阵。

随后重新采至少300个独立点，再检查覆盖、90%内点和RMS≤5%。命令应答和采样序号隔开阶段，防止串口缓存中的训练点混入独立数据。原始点不按旧校准模型筛掉；过期、重复序号和溢出数据被排除。

## 6. 单独确认安装轴向

```powershell
python tools/sensor_check.py --port COM9 --baud 115200 --stage mapping --output captures/mapping_01
```

分别输入MPU和磁力计正X/Y/Z朝机体哪个方向，选“前 后 左 右 上 下”。例 `前 右 下` 对应FLU的 `diag(1,-1,-1)`，不是你们安装结论。程序检查正交与右手系。

不确定就回车，保留矩阵并清除确认标志。椭球拟合不能决定安装轴，也不能修正磁偏角。确认标志随候选参数导出；编译宏 `FLIGHT_*_AXES_CONFIRMED` 仍可覆盖，烧录复查检查实际值。

## 7. 应用候选参数并烧录复查

生成文件保留 `--base` 指定头文件的其他参数。分步校准时先应用上一步已验证参数，或者把 `--base` 指向上一步候选文件进行合并。不会自动覆盖源码参数。

```powershell
Copy-Item -LiteralPath captures/accel_01/sensor_calibration.h -Destination Core/Inc/sensor_calibration.h
python tools/build_firmware.py --name sensor-cal-verified --define FLIGHT_APP_MODE=1
```

烧录 `build/sensor-cal-verified/quadcopter.hex` 后：

```powershell
python tools/sensor_check.py --port COM9 --baud 115200 --stage verify --verify-from captures/accel_01 --output captures/accel_post_flash_01
```

程序查询板上实际编译的加速度、磁场、两套映射及有效/确认标志，与候选记录逐一对比，再重新采独立数据。只改文件未重新烧录会被拒绝。本次上电零偏重新估计；候选含加速度时再采12个倾角，含磁场时另采磁场验证，全部通过才标为烧录复查通过。

烧录复查的12个倾角也是新的独立数据。如果复查期间中断，可同时指定原候选参数目录和中断的复查目录，从已完成的窗口继续：

```powershell
python tools/sensor_check.py --port COM12 --baud 115200 --stage verify --verify-from captures/accel_resume_01 --resume captures/post_flash_01 --output captures/post_flash_resume_01
```

`--resume` 指向中断的 `verify` 会话；`--verify-from` 指向生成候选参数的原 `accel` 会话。`--output` 要是新目录。

一次完成全部阶段可用：

```powershell
python tools/sensor_check.py --port COM9 --baud 115200 --stage all --output captures/full_01
```

请求的拟合或独立验收失败时不导出有效参数，已采数据与失败原因仍保存。磁力计缺失会跳过磁场阶段，不阻止MPU阶段。

## 8. 文件、回放和代码

输出有 `session.bin`（所有接收字节）、`raw.csv`（F1下采样）、`session.json`（完整统计和固件详情）、中文验收报告、`采样统计.csv`（每次完成的板上采样）；相关阶段另存六面统计和训练/独立磁场CSV。重连取消遗留活动任务，使用新编号，不合并旧统计。

```powershell
python tools/sensor_check.py --replay captures/full_01/session.bin --output captures/replay_01
python tools/sensor_check.py --offline captures/full_01 --output captures/offline_01
```

回放生成原始CSV和应答JSON；离线模式重新检查拟合及独立数据，都不能替代板上参数复查。

| 代码 | 职责 |
|---|---|
| imu_driver.c | 唯一驱动，身份/寄存器/通信诊断 |
| cal_service.c | 原始Welford统计、静止状态机和正常启动零偏API |
| sensor_data.c | 共享补偿、机体系转换及编译参数查询 |
| cal_wire.c/.h | F2重同步、F3编码、C/Python共享字段 |
| flight_app.c | 200Hz采集、命令邮箱、UART字节环和发送调度 |
| tools/sensor_check.py | 中文引导、验收、导出、报告和回放 |

F1保持版本1/61字节载荷；F2是12字节载荷，F3是84字节载荷/90字节整帧。INFO页0查模式/周期/错误，页1/2查芯片，页3/4/5查加速度/磁场/轴映射，页6查本次零偏。同一请求重发不会重新累计。

## 9. 传感器通过后再验证姿态

保存参数与报告，改回 `FLIGHT_APP_MODE=0`。先纯陀螺仪约90°旋转检查方向、倍率和dt，再恢复六轴β=0.05，验证水平、±30°和回水平。磁场及两套轴向均确认后再启用九轴，检查实际MAG_USED和干扰回退。

| 现象 | 先查 |
|---|---|
| 有F1却无应答 | JDY TXD→PA10、是否新固件、反向线路 |
| 完全无数据 | 该电脑传出COM、模块实际UART波特率、板子运行 |
| 校准反复重启 | 最后原因、振动、手持、模长和噪声；不要强制ready |
| 六面或独立倾角失败 | 错面、夹具倾斜、量程及传感器误差；不要先改β |
| 磁场覆盖不足 | 是否只水平转圈、各轴翻转是否充分 |
| 参数查询不一致 | 文件、构建宏与实际烧录HEX |
| ANO仍不发 | 新样本、零偏、dt和有效标志；不要删判断掩盖问题 |

阈值是首次台架工作目标，不是厂家精度保证。不包含飞行、电机工作时磁干扰补偿或完整温度补偿。
